- **exec:** только фиксированные `systemctl`/`openssl` + config-значения.

## Принятые риски (не эксплуатируются в нашем использовании)

| Риск | Почему не эксплуатируется | План |
|---|---|---|
| zod <4.6.6 (high, GHSA-mrhx-c7xc-m3w5): memory DoS на oversized collections | Наши схемы валидируют малые объекты (логин, промокод), body limit 1 МБ, больших коллекций на входе нет | плановый major-апгрейд zod 4.x |
| react-router 6.x (2 moderate): open redirect через `\` в `<Link>`, инъекция в SSR-гидрации | Редиректы только на фиксированные внутренние роуты; SSR нет (чистый SPA) | major-апгрейд react-router 7.x |

## Бэклог (не блокирует работу, до v1.48)

1. **JWT в query-string** для WS и media-ссылок (`?token=`) — попадает в access-логи nginx. Фикс: одноразовые media-токены или subprotocol-аутентификация.
2. **Admin-рассылка из бота** без персистентности (рестарт теряет остаток) — перевести на `broadcasts.startBroadcast`.
3. **Notifier без очереди/ретраев** — сбой Telegram = потерянное уведомление о продаже. Буфер с ретраем.
4. **Widget-level ErrorBoundary** — сейчас падение одного чарта убивает страницу целиком (меню живо).
5. **`ad.image` https-whitelist** на бэкенде при раздаче `/api/ads/panel`.
6. **Глобальный `unhandledrejection`** во фронтенде + toast.
7. **SSRF-фильтр приватных IP** в webhooks (URL задаёт только аутентифицированный админ — риск низкий).
8. **Полная транзакция completePayment** (markSuccess → expiry → payReferral одним куском).
9. **`wal_checkpoint(TRUNCATE)` в scheduler** — same-process, безопасно, но блокирует event loop до 5 с → PASSIVE.
10. **Персистентный счётчик срабатываний canary** — при «вечном удалителе» сейчас рестарт-луп каждые ~15 мин (cooldown в пределах процесса).

### Самовосстановление (уже работает на серверах)

- **Канарка** (quick_check каждые 15 мин, отдельное readonly-соединение) → при пропаже WAL: авто-перезапуск с переносом данных, cooldown/лимиты.
- **systemd Restart=always** — любой выход панели поднимается за 5 с.
- **auditd** (`-w /var/lib/tggate -p wa -k tggate-db`) — любое касание файлов БД логируется с именем процесса; просмотр: `ausearch -k tggate-db -i`.
- **Ночные проверки**: integrity_check 04:10, верификация свежего автобэкапа, полный бэкап 05:10 (readonly-снапшот + verify + ротация).
- **Оба сервера** (hand-door — боевой, Wild-Wolf — запасной) на v1.47.3, базы `quick_check: ok`.

### Честное ограничение

Аудит не даёт 100 % гарантии отсутствия ошибок — он закрывает все известные классы
отказов этой недели и добавляет самовосстановление. Следующий класс отказов, если
появится, будет пойман канаркой/auditd за ≤15 минут с именем виновника.
