## Дашборд

Живая нагрузка (CPU/RAM/сеть) через WebSocket, счётчики, трафик, статус
сервисов и срок SSL. Сверху — карточка первоначальной настройки: она
перечисляет незакрытые шаги и **исчезает сама**, когда всё готово.

![Дашборд](screenshots/01-dashboard.png)

## Клиенты

Квоты с прогресс-баром, срок действия, лимиты IP и скорости, протоколы.
Массовые действия и пагинация: выбранные клиенты сохраняются при переходе
между страницами.

![Клиенты](screenshots/02-clients.png)

## Продажи и аналитика

Выручка по дням, топ тарифов, конверсия теста, новые клиенты за период.

![Продажи](screenshots/03-sales.png)

## Живые логи

Подключения в реальном времени, фильтры по клиенту, IP, протоколу и
статусу, распознавание устройств, экспорт CSV за период.

![Логи](screenshots/04-logs.png)

## QR-коды

Генерация QR для Web Proxy и MTProto, PNG/SVG, кастомизация цветов и
размера, публичные страницы, статистика сканирований.

![QR-коды](screenshots/05-qr.png)

## Сайт-заглушка

Файловый менеджер и редактор, готовые шаблоны, SEO-поля и предпросмотр.

![Сайт-заглушка](screenshots/06-website.png)

## Telegram-бот

Админка продаж: статистика, тарифы, пользователи бота, выдача прокси и
баланса, рассылки.

![Telegram-бот](screenshots/07-bot.png)

## API-ключи

Ключи с разделением прав (read / write / full), ограничением по IP и сроку

![API-ключи](screenshots/08-api-keys.png)

## Для разработчиков

Документация публичного API, список событий вебхуков, примеры на Python и

![Для разработчиков](screenshots/09-developers.png)

## Обновления

Версии панели, Telemt и SSL-сертификата, автопроверка, канал обновлений и
история обновлений с живым прогрессом.

![Обновления](screenshots/10-updates.png)

## Настройки

Две колонки: категории слева, поля справа. Поиск по всем настройкам сразу —
по подписи, по значению и по названию категории. Изменения сохраняются сразу
по каждому полю, видно, что сохранилось и что можно вернуть. Опасные
действия вынесены в отдельную зону.

![Настройки](screenshots/11-settings.png)

## Публичный статус

Страница статуса проекта без авторизации — можно дать пользователям.

![Статус](screenshots/12-status-public.png)

## География

Карта мира с распределением подключений по странам, флаги, рейтинг стран,
фильтр по диапазону дат.

![География](screenshots/13-geo.png)

## Движок Telemt

Телеметрия движка: качество ME-пула, NAT/STUN, самопроверка, гейты,
апстримы, таблица TLS-отпечатков.

![Движок](screenshots/14-engine.png)

## Вебхуки

Подписки на события панели, кнопка «Тест» с немедленным результатом и
статус последней доставки по каждой подписке.

![Вебхуки](screenshots/15-webhooks.png)

## Журнал действий

Кто и когда менял данные панели: фильтры по администратору и типу действия,
поиск, пагинация и экспорт CSV. Пишется автоматически на каждый изменяющий
запрос.

![Журнал действий](screenshots/16-audit.png)

## Проверка системы

Диагностика по кнопке: версии, сервисы, ресурсы, целостность базы,
свежесть бэкапов, безопасность и уведомления. Значения секретов не
показываются — только факт наличия и стойкость.

![Проверка системы](screenshots/17-diagnostics.png)
