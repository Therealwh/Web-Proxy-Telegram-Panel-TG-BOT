# 🤖 Telegram-бот продаж TGGATE

Бот написан на [grammY](https://grammy.dev) (Node.js) и работает внутри
процесса панели — отдельный сервис не нужен.

## Настройка шаг за шагом

1. Откройте [@BotFather](https://t.me/BotFather) → `/newbot` → получите токен
2. В панели: **Telegram бот** → вставьте токен → включите бота → «Сохранить»
3. Задайте приветственное сообщение (переменные: `{имя}`, `{ссылка}`, `{дата}`)
4. Создайте тарифы: название, длительность в днях, цена, протоколы
5. Для уведомлений админу: **Настройки → Уведомления** → токен + chat ID

## Команды бота

| Команда | Описание |
|---|---|
| /start | Приветствие и список тарифов |
| /help | Помощь |

Кнопка **«📱 Мой доступ»** — текущие ссылки и срок действия.

## Логика покупки

1. Клиент выбирает тариф → создаётся платёж со статусом `pending`
2. Оплата: через подключённого провайдера или вручную
3. После подтверждения (`payment.success`) бот:
   - создаёт клиента `tg<telegram_id>` или продлевает существующего
   - отправляет ссылки Web Proxy и/или MTProto (по протоколам тарифа)
   - уведомляет администратора

## Платёжные провайдеры

Вебхуки (публичные, без авторизации панели):

- **ЮKassa**: `POST /api/payments/webhook/yookassa`
  (id платежа передаётся в `metadata.tggate_payment_id`)
- **CryptoBot**: `POST /api/payments/webhook/cryptobot`
  (проверка HMAC-подписи `crypto-pay-api-signature`)

Ручное подтверждение: `POST /api/payments/{id}/confirm` (админ).

## Промокоды

**Платежи → Промокоды**: скидка в % или фиксированная, лимит использований,
только на первый платёж, срок действия. Проверка: `POST /api/payments/promo/check`.
