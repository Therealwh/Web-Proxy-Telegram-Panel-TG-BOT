# 🤖 Telegram-бот продаж TGGATE

Бот написан на [grammY](https://grammy.dev) (Node.js) и работает внутри
процесса панели — отдельный сервис не нужен.

## Настройка шаг за шагом

1. Откройте [@BotFather](https://t.me/BotFather) → `/newbot` → получите токен
2. В панели: **Telegram бот** → вставьте токен → включите бота → «Сохранить»
3. Задайте приветственное сообщение (переменные: `{имя}`, `{ссылка}`, `{дата}`)
4. Создайте тарифы: название, длительность в днях, цена, протоколы
5. Для уведомлений админу: **Настройки → Уведомления** → токен + chat ID

## Команды бота

| Команда | Описание |
|---|---|
| /start | Приветствие и список тарифов |
| /help | Помощь |

Кнопка **«📱 Мой доступ»** — текущие ссылки и срок действия.

## Логика покупки

1. Клиент выбирает тариф → создаётся платёж со статусом `pending`
2. Оплата любым способом (см. ниже)
3. После подтверждения бот:
   - создаёт клиента `tg<telegram_id>x<N>` или продлевает существующего
   - отправляет ссылки Web Proxy и/или MTProto (по протоколам тарифа)
   - уведомляет администратора

## Способы оплаты

| Способ | Где включается | Как подтверждается |
|---|---|---|
| 💰 Баланс | пополнение в кабинете | списание мгновенно |
| 🪙 CryptoBot | Панель → Токен CryptoBot | вебхук `POST /api/payments/webhook/cryptobot` (HMAC) |
| 💳 ЮKassa | Панель → shopId + секретный ключ | вебхук `POST /api/payments/webhook/yookassa` (верификация через API) |
| ⭐ Telegram Stars | Панель → тумблер «⭐ Telegram Stars» + курсы (1 ⭐ = ₽ / $) | инвойс XTR прямо в чате: `pre_checkout_query` → `successful_payment` → `completePayment` |
| 🏦 Карта админа | Панель → карта/СБП/банк | клиент жмёт «Я оплатил» → чек админу → подтверждение |

Stars: цена тарифа конвертируется автоматически (`звёзды = цена / курс`,
округление вверх, лимит инвойса 2500 ⭐). Подключать провайдера в BotFather
не нужно. Возвраты — вручную через @BotFather. Ручное подтверждение оплаты:
`POST /api/payments/{id}/confirm` (админ).

## Личный кабинет

- Список всех прокси клиента: статус и срок по каждому.
- Под каждым прокси — кнопки подключения:
  «🌐 Подключить ВЕБ прокси» и/или «🔌 Подключить MTProto прокси»
  (по купленным протоколам, клик = Telegram сразу предлагает подключиться)
  и «♻️ Продлить».
- Продление: прокси с двумя протоколами (например, тестовый) сначала
  спрашивает «Что продлеваем?» — только Web / только MTProto / оба — затем
  показывает тарифы выбранного типа с ценой и сроком. Выбранный набор
  протоколов применяется после оплаты (`payments.renew_protocols`).
- Продление и покупка списывают с **общего баланса** пользователя.
- Пополнение баланса: фиксированные суммы или своя.

## Пользователи бота (панель)

**Панель → Telegram бот → Пользователи бота**: все, кто взаимодействовал
с ботом (таблица `bot_users`), даже без покупок. Рядом с Telegram ID —
@username (кликабельный) или имя; раскрытие по стрелке — список прокси.
Действия: выдать/списать баланс, написать через бота.

## Промокоды

**Платежи → Промокоды**: скидка в % или фиксированная, лимит использований,
только на первый платёж, срок действия. Проверка: `POST /api/payments/promo/check`.
