# 📱 QR-коды

Для каждого клиента генерируются QR-коды обоих протоколов.

## Где посмотреть

- **Клиенты** → кнопка QR в строке клиента
- **QR-коды** — расширенная страница с кастомизацией

## Возможности

- Форматы: PNG, SVG
- Кастомизация: цвет кода, цвет фона, размер (256–2048 px)
- Публичная страница: `https://домен/qr/{id}` — отправьте клиенту,
  он увидит оба QR и кнопки подключения
- Статистика сканирований (по типу протокола)
- Отправка QR клиенту в Telegram из панели

## API

```bash
# PNG 512px
GET /api/qr/client/{id}/web.png?token=<JWT>

# SVG с кастомными цветами
GET /api/qr/client/{id}/mtproto.svg?token=<JWT>&color=%230088cc&bg=%23ffffff&size=1024

# Base64 (для своих ботов)
GET /api/v1/clients/{id}/qr    # публичный API, по API-ключу
```

## Перевыпуск ссылок

**Клиенты → 🗝 (новый секрет)** — старые ссылки и QR перестанут работать,
QR обновятся автоматически.
