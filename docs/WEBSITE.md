# 🌐 Сайт-заглушка

Домен, который обслуживает прокси, должен выглядеть как обычный сайт —
это маскировка от активного зондирования. Обычные HTTP-запросы Telemt
отправляет в decoy — ваш сайт из `/var/lib/tggate/website`.

## Управление

**Панель → Сайт-заглушка**:

- 📂 Файловый менеджер (создание/правка/удаление/загрузка файлов)
- ✍️ Редактор кода с моноширинным шрифтом
- 📤 Загрузка файлов (до 5 МБ)
- 🎨 Готовые шаблоны: «Сайт на ремонте», «Автомобили», «Женский портал»
- 👀 Кнопка «Открыть сайт» для предпросмотра

После каждого изменения панель автоматически вызывает reload Telemt,
чтобы тот перечитал статику.

## Рекомендуемые файлы

| Файл | Назначение |
|---|---|
| index.html | Главная страница |
| robots.txt | Правила для поисковиков |
| sitemap.xml | Карта сайта |
| favicon.ico / .svg | Иконка вкладки |
| manifest.json | PWA-манифест |

## Важно про маскировку

- Панель живёт на секретном пути `/cp-xxxxxx/` — не публикуйте его
- Публичные страницы `/qr/{id}` и `/status` не выдают признаков панели
- Заголовки Server скрыты на уровне Caddy
- До распространения ссылок проверьте: обычный `GET /` возвращает сайт,
  а не ошибку прокси

## Свой шаблон

Просто загрузите свои HTML/CSS/JS через файловый менеджер.
Поддерживается многостраничность (about.html и т.д.) — Telemt отдаёт
файлы по путям автоматически.
