📋 ПРОМТ: Создание панели управления Telegram-прокси (Telemt) с поддержкой Web Proxy и MTProto
🎯 Задача
Создать с нуля полноценную панель управления для Telemt — единого прокси-сервера, который обеспечивает:
Web Proxy для Telegram
MTProto Proxy на порту 8443/tcp
Панель должна автоматически устанавливаться на чистый VPS с Ubuntu 22.04+ / 24.04+ одной командой, быть красивой, современной, полностью на русском языке, с понятной структурой категорий и подписанных настроек.
⚠️ ВАЖНО: Используется только Telemt как единый прокси-сервер для обоих протоколов (Web Proxy + MTProto). Отдельные MTProto-прокси или Xray/VLESS/Hysteria2 НЕ НУЖНЫ.
🏗️ Архитектура и стек
Панель должна работать как единый комплекс:
Telemt — единый прокси-сервер (Web Proxy + MTProto на порту 8443)
Панель управления — веб-интерфейс (Node.js/Express или Python/FastAPI + красивый frontend на React/Vue или чистый HTML/CSS/JS)
Caddy — для HTTPS сертификатов и заглушки на домене (маскировка под обычный сайт)
Nginx — reverse proxy для панели и API
SQLite — для хранения пользователей, статистики и логов
Systemd — для автозапуска сервисов



📦 Установка одной командой
Должна быть единая команда установки вида:
apt-get -o DPkg::Lock::Timeout=600 update && apt-get -o DPkg::Lock::Timeout=600 install -y curl ca-certificates git && bash -c "$(curl -fsSL --proto '=https' --tlsv1.2 https://raw.githubusercontent.com/ВАШ_ЮЗЕР/ВАШ_РЕПО/main/install.sh)"

При установке в интерактивном режиме скрипт должен спрашивать:
🌐 Домен для панели (например, proxy.example.com)
📧 Email для получения Let's Encrypt SSL сертификата
👤 Логин администратора (латиница)
🔑 Пароль администратора (минимум 8 символов, проверка сложности)
🌍 Внешний IP VPS (автоопределение + возможность переопределить)
Скрипт должен:
Проверять root-права
Проверять, что VPS чистый (нет конфликтующих сервисов на 80/443)
Устанавливать все зависимости (curl, git, ca-certificates, ufw, nginx, caddy и т.д.)
Автоматически настраивать firewall (UFW) — открывать 80/tcp, 443/tcp, 8443/tcp
Настраивать Caddy для HTTPS заглушки (показывает обычный сайт на главном домене)
Настраивать Nginx как reverse proxy к панели
Устанавливать и настраивать Telemt с поддержкой Web Proxy и MTProto на порту 8443
Запускать telemt и панель через systemd
Создавать alias команду sudo WPP для быстрого управления
